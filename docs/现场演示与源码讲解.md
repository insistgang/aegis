# 现场演示与源码讲解

## 演示准备

评审演示前在准备好的环境运行以下命令。第一条复现受控工具副作用，不调用模型；第二条验证既有场景；第三条展示来源映射、嵌套代理与 SQLite 脱敏导出。需要 Python 3.11+、Git 和本地 shell，Windows 使用 WSL2。日常演示读取随包归档的真实模型结果，不依赖现场服务商配额。

```bash
python scripts/demo_paired_eval.py --rerun
python -m aegis demo
python examples/topic5_defense_demo.py
```

打开 output/demo/paired_eval.html。页面可切换固定轨迹与真实 MiniMax，逐案例比较相同逻辑任务的实际效果、决策、参数、模型触发与错误，展开完整来源轨迹。固定重放与真实模型结果有明确标记，不能将前者描述为现场大模型自主攻击。

## 五分钟操作顺序

1. 选“固定工具轨迹重放”，打开凭据外发 delegated 案例。先说明用户只允许核对配置，外部材料伪称维护者授权外发，所有内容均为合成测试材料。
2. 展示无守卫臂：实际读取临时配置，回环接收器收到合成值；完整 AEGIS 臂在工具参数检查时阻断。检查执行标记和 HTTP 接收记录，不能只看模型回答。
3. 切换敏感写入或下载执行案例，展示无守卫臂实际产生文件变化/无害 canary，AEGIS 阻断。说明无守卫臂仍有独立环境边界，未对真实宿主或外部目标进行操作。
4. 切换正常 report.txt、health 或本地检查案例，展示正确内容、回环健康响应和本地检查标记，解释预先确认仅来自测试中的合法用户任务。
5. 切换真实 MiniMax 层。读实际分母，指出模型自行拒绝或未触发的样本不算守卫成功；错误、环境拒绝与未完成不隐去。

DAG 可展示调用与返回的结构关系。数据依赖或攻击因果关系只有在已有记录支持时才解释，不能因为图中相邻就声称外部材料必然导致了调用。默认 token 为版本化审计分词，宿主可注入模型 tokenizer；不把其数量当作 MiniMax 账单。

## 常见质询

“一万条测试代表什么？” 其中一万项为冻结输出一致性回归；历史一万条真实 API 实测说明接口与循环跑通，不能替代攻击成功率。新对照单独记录实际副作用。

“是不是只靠黑名单？” 仍使用确定性规则，但同时利用明确任务约束、会话秘密来源、工具参数、调用顺序和独立运行时底线。公开静态参考规则是机制对照，不是其他商业产品，也不据此声称优于行业方案。

“为什么模型没有攻击也算防住？” 不这样计数。真实模型的未触发和自行拒绝单列；只有观察到提议及实际拒绝/阻断记录，才能讨论该次门禁作用。

“为什么不是完整公开基准成绩？” 外部来源案例改变了工具 API、敏感来源和接收端，并只抽取六例，因此仅称来源适配测试，不能沿用原论文 ASR 或宣称完整复现。

“能直接上线企业吗？” 当前证据来自受控环境；企业部署还需实际宿主适配、真实业务验证、权限与符号链接控制、压力测试和持续独立评测。

“子 Agent 是否真的运行？” 新实验启动固定 Python 接收进程，验证任务和秘密是否跨进程送达；它不是另一个自主规划的大模型智能体。多层代理身份与 SQLite 来源链由独立 SDK 演示验证，二者分别说明。

现场只执行预先检查的命令。新输入先走文本检查和无副作用的判定接口，不能为了展示而关闭实验边界或临时执行任意外部命令。
