# 六项安全能力修复验收报告

本次开发对应赛题 5 的工具策略、任务对齐、跨 MCP 与子 Agent 溯源及抗绕过能力。修复前的问题均有失败回归，修复后同时检查正常调用和拒绝路径。验证不调用外部模型，不对真实宿主凭据或外部目标执行攻击。

| 问题 | 当前实现 | 验收入口 |
| --- | --- | --- |
| 工具改名绕过 | SDK 与 MCP 共用工具语义归一；名称别名、命名空间和明确的路径、内容、URL、命令参数形状共同决定操作类别，保留原始名称与参数 | test_tool_semantics.py、test_topic5_integration.py |
| 未知或编码秘密传递 | 从敏感文件采集完整内容与凭据字段，识别原值、短值边界、两层 Base64、hex、URL 编码及拆分/转义；网络和子任务强制阻断，确认不能覆盖 | test_secret_taint.py、SQLite 原始文件检查 |
| 假基线配置 | 运行时独立执行强制阻断底线；加载配置时证明规则覆盖范围，拒绝不可能条件和附加限制，手工创建空 PolicySet 也保留底线 | test_policy_floor.py |
| 粗粒度意图对齐 | 合法用户消息保留明确文件范围、只读、禁联网和禁委派约束；检查计划参数、顺序与已观察调用序列；每个代理独立保存计划 | test_task_alignment.py、实际 SDK/MCP 门禁集成测试 |
| 溯源缺失 | 唯一 agent_id 与 parent_agent、原始 call_id 和调用节点关联；完整返回脱敏持久化；错误、重复和不唯一的关联被拒绝；资源也可标注代理和 MCP | test_topic5_integration.py |
| 长文本漏扫及坐标错误 | 删除首尾截断，完整规范化与检测；保留字符串拼接、Unicode 及跨消息来源映射；不同代理的跨轮片段互不混用 | test_long_context.py |

来源记录含原文字符范围、token 索引范围、token ID、tokenizer 版本和来源节点。默认 `aegis-unicode-v1` 为包含空白与标点的审计分词器，不冒充 MiniMax 模型或计费 token；宿主可通过 `AegisGuard(tokenizer=...)` 注入带原文偏移的分词器。完整工具返回通过现有 JSON detail 字段保存，无破坏性数据库迁移。

## 可复核流程

```bash
python -m pytest -q
python -m aegis demo
python examples/topic5_defense_demo.py
```

最后一条命令使用内存门禁与临时 SQLite，输出 12 项防护检查、DAG、时序、来源映射和完整脱敏审计。结果归档在 [离线演示证据](evidence/topic5_defense_demo.json)。节点中的 `declared` 表示放行后声明的子任务；实际启动由宿主完成后调用 `register_agent` 登记为 `registered`。沙箱本身不创建真实子进程，不能把声明节点当作已运行的分布式工作负载。

## 语料版本与历史证据

并行会话补充了敏感动作内容规则，并增加了循环的内容隔离。本次保留这些改动并独立核对：同一万条合成语料中，攻击阻断 3753、询问 0、放行 1287；良性误拦 10。相较旧规则有 2242 条攻击记录改变，标签和本地字符评分未修改。新快照仅用于当前实现的回归，不是独立人工判定标准，也不构成泛化收益证明。

[变化清单](evidence/topic5_offline_rule_review.json) 包含每条变化的 ID、类别和前后判定；[修复前快照](evidence/row_oracle_before_topic5.json) 保留旧版对照。历史 MiniMax 原始 JSONL、语料、回执与 token 统计不变。3753 是当前规则离线复测，1511 是历史模型批次的内容阻断计数，不能互相覆盖。当前循环遇到内容 `ask` 或 `block` 会发送隔离说明，不把原文送入模型。

## 实际测试环境与边界

本机为 Apple M5、16 GiB 内存、macOS 26.5.2、arm64；项目环境为 Python 3.14.7、PyYAML 6.0.3、pytest 9.1.1。这是测试设备记录，不是最低配置或容量保证。另检查干净环境安装及打包后运行；最终统计写入交付校验记录。

路径仅作词法规范化，不解决符号链接与实际文件权限；命令检测不是完整 shell 或程序语义分析。工具语义只覆盖明确映射和参数形状，不声称理解任意加密、自定义协议。秘密变换检查为有界标准编码，不能覆盖任意加密或隐写。任务约束支持明确表达，下载、写入和执行的序列判断为启发式，不代表完整数据流证明。企业线上部署和压力容量尚未验证。后续增加的受控副作用无守卫对照与付费模型测试单独记录在 [攻防对照报告](攻防对照实验报告.md)，不改本节历史结果。
