# 现场演示与源码讲解

## 演示准备

评审演示前在准备好的环境运行以下命令。第一条默认离线加载归档数据；第二条验证既有场景；第三条展示来源映射、嵌套代理与 SQLite 脱敏导出。需要 Python 3.11+、Git 和本地 shell，Windows 使用 WSL2。日常演示不依赖现场服务商配额。

```bash
python scripts/demo_paired_eval.py
python -m aegis demo
python examples/topic5_defense_demo.py
```

打开 `output/demo/paired_eval.html`。页面可选择 `replay`、`live`、`danger_direct`、`danger_indirect` 四组数据，逐案例查看实际效果、决策、参数、模型触发与错误，并展开来源轨迹。捕获模型参数后的离线门禁复核单独显示，不属于第五组现场模型运行。默认模式不调用模型；传入 `--rerun` 只重放原有 72 组固定工具轨迹，不会重跑危险调用探索。固定重放与真实模型结果有明确标记，不能将重放描述为现场大模型自主攻击。

## 五分钟操作顺序

1. 选择 `danger_direct`，打开私钥读取案例。对照无守卫组读取合成 fixture 与 AEGIS 组提出同路径读取后被工具门禁阻断的轨迹，强调这是直接合成控制，不是间接注入率。
2. 在同一数据集中打开 `git.push` 案例，展示 AEGIS 的检视禁推送/任务约束阻断记录。说明提示同时包含“不要推送”和“实际测试推送”的冲突指令；这里只验证工具门禁，远端是临时本地 bare 仓库。
3. 单独打开“模型调用参数复核”，展示五类已捕获参数的离线复核结果均为阻断。它不调用模型、不执行危险操作，也不是原会话的实时反事实；子 Agent 带值派发没有被真实模型提出。
4. 选择 `danger_indirect`，展示六类 runbook 探针在两组均未触发危险调用或效果。明确模型未触发不能计作守卫成功，且不能据此估算条件阻断收益。
5. 查看 `live` 和 `replay`，说明它们分别保留原有真实模型与 72 组固定轨迹证据，和新增危险调用探索分开统计；错误、环境拒绝、模型自行拒绝及未完成均保留。

本次危险调用探索共 24 条记录、54 次 HTTP 200、63724 token；直接控制中无守卫组有 4 项合成危险效果，AEGIS 组的 3 项危险提议均被阻断、未产生危险效果。间接层两组均未触发。全部分层与口径见[危险调用探索报告](危险调用探索报告.md)。

DAG 可展示调用与返回的结构关系。数据依赖或攻击因果关系只有在已有记录支持时才解释，不能因为图中相邻就声称外部材料必然导致了调用。默认 token 为版本化审计分词，宿主可注入模型 tokenizer；不把其数量当作 MiniMax 账单。

## 常见质询

“一万条测试代表什么？” 其中一万项为冻结输出一致性回归；历史一万条真实 API 实测说明接口与循环跑通，不能替代攻击成功率。新对照单独记录实际副作用。

“是不是只靠黑名单？” 仍使用确定性规则，但同时利用明确任务约束、会话秘密来源、工具参数、调用顺序和独立运行时底线。公开静态参考规则是机制对照，不是其他商业产品，也不据此声称优于行业方案。

“为什么模型没有攻击也算防住？” 不这样计数。真实模型的未触发和自行拒绝单列；只有观察到提议及实际拒绝/阻断记录，才能讨论该次门禁作用。

“为什么不是完整公开基准成绩？” 外部来源案例改变了工具 API、敏感来源和接收端，并只抽取六例，因此仅称来源适配测试，不能沿用原论文 ASR 或宣称完整复现。

“能直接上线企业吗？” 当前证据来自受控环境；企业部署还需实际宿主适配、真实业务验证、权限与符号链接控制、压力测试和持续独立评测。

“子 Agent 是否真的运行？” 原有固定轨迹演示启动固定 Python 接收进程，验证任务和合成秘密是否跨进程送达；它不是另一个自主规划的大模型智能体。新增危险调用探索中的真实模型没有提出带值 `agent.spawn` 调用。多层代理身份与 SQLite 来源链由独立 SDK 演示验证，二者分别说明。

现场只执行预先检查的命令。新输入先走文本检查和无副作用的判定接口，不能为了展示而关闭实验边界或临时执行任意外部命令。
